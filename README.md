
# Reinforcement Learning for Formula 1 Race Strategy

Code accompanying the paper:

**Reinforcement Learning for Formula 1 Race Strategy in a Stochastic Event-Driven Simulator**

by Giacomo Iannucci and Alexandros Beskos.

This repository contains the code used for the main reinforcement-learning experiments in the paper, including the stochastic Formula One race simulator, PPO training and evaluation, the domain-informed benchmark comparison, ablation studies, robustness experiments, and bootstrap uncertainty analysis.

The repository also contains a script for retrieving and processing the publicly available OpenF1 data used to calibrate and assess race-specific quantities.

## Files

### `download_openf1_data.py`

Downloads lap timing, driver, stint, tyre-compound, and pit-stop information for the 2026 Japanese Grand Prix from the public OpenF1 API.

The script processes the retrieved data and produces formatted Excel files containing the complete race-lap data and the subset of laps with complete sector timing information.

### `race_strategy_rl.py`

Contains the stochastic event-driven race simulator and the reinforcement-learning implementation used for the main experiments in the paper.


## Requirements

Python 3.10 or later is recommended.

Install the required packages with:

python -m pip install numpy pandas matplotlib torch requests openpyxl


## Downloading the OpenF1 data

Run:

python download_openf1_data.py


The script creates a directory containing the processed 2026 Japanese Grand Prix data in Excel format.

The underlying race data are obtained from the publicly accessible OpenF1 API:

https://openf1.org/

## Main PPO experiments

Run:

python race_strategy_rl.py --mode main

This trains the PPO controller across the random seeds used for the main analysis and performs the paired held-out evaluation against the domain-informed benchmark.

The main evaluation uses common stochastic race scenarios for the PPO controller and benchmark so that differences in performance are evaluated under matched underlying race conditions.

The analysis also produces the bootstrap uncertainty estimates and behavioural summaries used in the paper.

## Reproducibility

Random seeds are explicitly controlled in the code.

The principal policy comparison is performed using paired stochastic scenarios, so that the PPO controller and the domain-informed benchmark are evaluated under the same underlying episode conditions.

The simulator parameters, PPO hyperparameters, evaluation protocol, ablation definitions, and robustness perturbations used by the scripts correspond to those described in the accompanying manuscript.

## Data

The empirical race data used in the study are obtained from the publicly accessible OpenF1 API.

All additional experimental data are generated by the stochastic race simulator implemented in `f1_race_strategy_rl.py`.
